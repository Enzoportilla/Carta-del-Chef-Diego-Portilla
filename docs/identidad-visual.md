# Identidad visual

## Logo
- Archivo: `public/img/logo-chef-diego-portilla.png` (PNG, 641 × 394 px, fondo oscuro).
- Contenido: gorro de chef sobre montañas nevadas con estrellas; debajo, "CHEF" en dorado y
  "DIEGO PORTILLA" en crema con borde dorado; ornamento dorado con una estrella al pie.
- Estilo: elegante, gastronómico, con aire andino/montaña. Dorado + crema sobre negro.

## Paleta de colores (muestreada del logo)
| Uso sugerido | Color | Hex |
|---|---|---|
| Fondo principal | Negro azulado | `#060B0F` |
| Fondo secundario / tarjetas | Grafito | `#13171B` |
| Texto principal / títulos | Crema | `#F0E2B3` |
| Acentos claros | Marfil | `#F8F1CD` |
| Acento / botones / precios | Dorado | `#AF8B55` |
| Acento cálido (estrella) | Ámbar | `#DE9A51` |

## Tipografía (en uso)
- Títulos y nombres de producto: *Cinzel* 600.
- Texto y precios: *Lato* 400 y 700.

## Notas
- El logo tiene fondo negro (no transparente): usarlo sobre fondos oscuros.
- Si se necesita versión con fondo transparente o en vector (SVG), pedirla al cliente.
